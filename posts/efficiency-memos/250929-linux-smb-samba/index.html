【效率备忘】Linux 启用 SMB 文件共享

对于跨平台的局域网文件传输，使用 SMB 协议是非常简洁方便的，这是微软开发的一种应用层网络传输协议，Windows 系统会提供原生支持，其他平台可能要借助第三方工具，本文会给出 Debian 系的 Linux 设备使用 Samba 启动 SMB 服务的流程，并给出原理简述以方便理解。

📦 安装 Samba

sudo apt update
sudo apt install samba

Samba 会自动在系统中创建一个开机自启的服务smdb，使用下面指令查看状态：

sudo systemctl status smbd

🔐 创建用户

SMB 一般有注册用户和匿名用户 (Guest) 两种访问方式，考虑到安全问题，建议使用注册用户访问。Linux 启动 Samba 后就变成了一个 SMB 服务器，首先要在服务器中创建用户，由于涉及文件操作，Samba 用户名必须与 Linux 系统中的某个用户名一致以便权限控制，以下命令都基于一个虚构的主用户semones：

  1. 添加用户到 Samba
sudo smbpasswd -a semones  # 填自己的用户名
  1. 设置密码
sudo smbpasswd 123456  # 设置一个密码

此密码与 Linux 系统无关，独立存在于 Samba 本地数据库。

  1. 激活用户
sudo smbpasswd -e semones
# 禁用用户可使用 sudo smbpasswd -d semones
# 删除用户可使用 sudo smbpasswd -x semones

其他设备若使用此凭证登陆，后续的文件操作都是以 Linux 系统中 semones 的身份来执行，权限一致

  1. 查看信息 (非必须)
sudo pdbedit -L        # 查看用户列表
sudo pdbedit -Lv semones  # 查看详细信息

详细信息中可以看到 Samba 账户包含的User SID等信息，说明 Samba 在模拟 Windows 行为来实现 SMB。

📁 创建共享目录

  1. 在用户目录下创建一个名为 Share 的文件夹
mkdir -p ~/Share
  1. 设置权限
sudo chmod 755 ~/Share
  • 7 (所有者权限)：4+2+1 = 读 (r) + 写 (w) + 执行 (x) → rwx
  • 5 (组用户权限)：4+0+1 = 读(r) + 执行(x) → r-x
  • 5 (其他用户权限)：4+0+1 = 读 (r) + 执行 (x) → r-x
  • 完整的权限字符串：rwxr-xr-x 注：本例是基于一个虚构的主用户semones，默认为文件夹所有者，如果是其他用户，要修改组用户权限。

⚙️ 配置共享目录

  1. 打开配置文件 Samba 的配置文件在/etc/samba/smb.conf，所有者是root，无法直接修改，提供几种方法：
  • 右键samba文件夹选择“以 root 身份打开”，再打开smb.conf文件。
  • 在终端中使用 nano 编辑：
sudo nano /etc/samba/smb.conf
  1. 在末尾添加配置 一个包含必要元素的样例：
[Share]
   path = /home/semones/Share
   guest ok = no
   read only = no
  • [Share]：共享名，其他设备看到的名字
  • path：共享目录的路径
  • guest ok：访问控制，no表示必须登录
  • read only：权限控制，no表示允许读写
  1. 重启服务确保读取新配置
sudo systemctl restart smbd

此时已经可以用其他设备登录并操作文件！

🛡️ 配置防火墙

Samba 传输会受防火墙影响 直接终端输入

sudo ufw allow Samba

自动添加规则。

🔄 兼容性问题解决方案

其他设备特别是苹果可能会出现兼容性问题，需要在基础配置后添加：

   vfs objects = catia fruit streams_xattr
   fruit:nfs_aces = no
  1. vfs objects制定启用 Samba 的哪些插件：
  • catia：文件名兼容
  • fruit：文件系统语义兼容
  • streams_xattr：Windows 数据流兼容
  1. fruit:nfs_aces是fruit插件的详细设置： no表示不使用 Linux/NFS 的 ACL，而是用自己的 fruit 机制来模拟 macOS 的权限规则。
